# 앱 디자인 v2 — "AI로 만든 티" 빼기

2026-11-16. 대상: 사장님 앱(`/app`), 직원 화면(`/app/me`), 운영자 백오피스(`/admin`), 로그인·온보딩.
랜딩 페이지는 건드리지 않는다.

## 왜

지금 화면은 깔끔하지만 생성형 대시보드의 공식을 그대로 따른다. 사장님이 "AI가 만든 것 같다"고 느끼는 지점은 이렇다.

| 지금                                                                                                              | 왜 티가 나나                                                 |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 모든 화면 제목 위에 주황 대문자 꼬리표 (`TODAY · 11.16`, `AI REVIEW`, `OPERATIONS`, `BACK OFFICE · 운영팀 전용`)  | 내용이 없는 장식. 한국어 업무 앱에 영어 대문자 라벨은 어색함 |
| 첫 카드만 남색으로 채운 KPI 카드 3~4장 + 큰 숫자 + 초록 알약 증감                                                 | 생성형 대시보드의 기본 배치                                  |
| 모든 것이 같은 16px 둥근 카드                                                                                     | 정보 위계 없이 같은 상자만 반복                              |
| 주황 그라데이션 알약 버튼                                                                                         | 장식용 그라데이션                                            |
| `✦` 반짝이 아이콘 (AI 답글 쓰기, 템플릿 초안, AI로 다시 쓰기)                                                     | "AI" 상투 기호                                               |
| 가운뎃점으로 이어 붙인 메타 (`채널 수집 · 11.15 19:52`, `오늘 · 합계`, `스탠다드 더블 · 투숙 11.13 · 작성 11.15`) | 템플릿 문구                                                  |
| 점 + 알약 상태 배지를 모든 곳에                                                                                   | 상태가 아닌 것까지 배지                                      |
| 그라데이션 면을 깐 곡선 그래프 + 모든 점 표시                                                                     | 장식 차트                                                    |
| 사이드바 업장 버튼의 주황 사각 아바타 "스"                                                                        | 앱 아이콘 흉내                                               |

## 기준으로 삼은 실제 서비스

숫자를 매일 보는 업무 도구 중 군더더기 없는 것들:

- **Stripe 대시보드**: 오늘 요약을 카드 여러 장이 아니라 한 줄 띠로. 숫자는 왼쪽 정렬, 증감은 색 글자만
- **Linear**: 제목 하나, 꼬리표 없음. 회색 단계와 얇은 선으로 위계. 버튼은 작고 각진 모서리(6px)
- **토스페이먼츠 상점관리자**: 한국어 업무 문구. 표 중심. 강조는 굵기와 색 하나

## 토큰

| 이름    | 값                                        | 쓰임                                                            |
| ------- | ----------------------------------------- | --------------------------------------------------------------- |
| 바탕    | `#F6F7F9`                                 | 본문 바탕 (지금과 비슷하게 차가운 회색)                         |
| 면      | `#FFFFFF`                                 | 표·패널                                                         |
| 선      | `#E4E7EC` / 약한 선 `#EEF0F3`             | 구역 나눔. 그림자 대신                                          |
| 글자    | `#1C2B46` 남색 · `#475467` · `#667085`    | 제목 · 본문 · 보조                                              |
| 주 동작 | `#1C2B46` 남색 단색                       | 확정·저장·게시 같은 주 버튼                                     |
| 브랜드  | `#FF5800` 주황                            | 지금 메뉴 표시, 저장 전 고친 칸, 알림 점. 버튼 면에는 쓰지 않음 |
| 상태    | 지금 토큰 그대로 (ok · warn · bad · info) | 글자 + 연한 면                                                  |

- 모서리: 패널 10px · 입력칸·버튼 6px · 배지 4px. 알약은 토글·필터 칩에만
- 글꼴: Pretendard 하나. 제목 20px/700, 구역 제목 15px/600, 본문 14px, 표 13px, 보조 12px. 숫자는 늘 tabular-nums
- 그림자: 떠 있는 것(메뉴·모달·토스트)에만

## 배치 원칙

1. **화면 머리는 제목 + 한 줄 설명 + 오른쪽 동작.** 꼬리표 없음. 홈만 제목 자리에 날짜를 쓴다: `11월 16일 월요일`.
2. **요약 수치는 띠 하나.** 테두리 있는 패널 하나를 세로선으로 나눠 3~4칸에 넣는다. 칸마다 작은 라벨, 큰 숫자(26px/700), 그 아래 보조 한 줄. 남색 채움·알약 증감 없이 `+12.3%`처럼 색 글자로만 쓴다.
   ```
   ┌──────────────────┬──────────────────┬──────────────────┐
   │ 오늘 예약매출       │ 답글 기다리는 리뷰   │ 7일 안 정산 예정     │
   │ ₩4,820,000       │ 5건              │ ₩11,410,000      │
   │ 어제보다 +12.3%    │ 별점 3점 이하 3건   │ 7개 채널           │
   └──────────────────┴──────────────────┴──────────────────┘
   ```
3. **패널 머리는 제목과 숫자 하나.** 가운뎃점 메타 대신 필요한 정보 하나만 쓴다 (`채널별 예약매출` + 오른쪽 `합계 ₩4,820,000`).
4. **배지는 상태에만.** 정상·오류·확인 필요처럼 바뀌는 상태에만 쓰고, 점은 연동 상태에만. "템플릿 초안" 같은 종류 표시는 회색 글자로.
5. **AI 표시는 말로.** 반짝이 아이콘을 없애고 "답글 초안", "다시 쓰기"처럼 하는 일을 쓴다. 키가 없을 때만 "기본 문장" 표시.
6. **차트는 선 하나.** 면 그라데이션과 점을 없애고, 이번 달 점 하나만 찍는다. 축 글자는 보조색.
7. **사이드바는 조용하게.** 업장 버튼은 아바타 없이 업장 이름 + 객실 수. 지금 메뉴는 왼쪽 주황 2px 막대 + 흰 글자.
8. **운영자 화면도 같은 규칙.** `BACK OFFICE`는 상단 바에 작은 회색 글자로 한 번만 쓴다.

## 하지 않는 것

- 전체 색이나 브랜드를 바꾸지 않는다 (남색 + 주황 유지)
- 레이아웃 구조와 기능은 그대로. 겉모양과 문구만 다듬는다
- 랜딩 페이지는 그대로
