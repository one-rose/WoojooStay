# 앱 디자인 v3 — 홈페이지(랜딩) 브랜드 맛 더하기

2026-11-21. 대상: 웹 관리화면(`/app`, 직원 `/app/me`, 로그인·온보딩), 네이티브 앱(Android · iOS).
랜딩은 건드리지 않는다. 운영자 백오피스(`/admin`)는 같은 토큰 파일을 써서 바탕·모서리·버튼 모양이 함께 바뀐다 (대표 버튼은 쓰지 않음).

## 왜

v2(`PMS-DESIGN-V2.md`)에서 "AI로 만든 티"를 빼면서 랜딩의 주황 알약 버튼·큰 둥근 카드까지 같이 빠졌다.
그 결과 화면이 차가운 회색 업무 도구처럼 보여 홈페이지와 같은 서비스로 느껴지지 않는다.
v3는 **v2의 배치 원칙(꼬리표 없음 · 요약 띠 하나 · 배지는 상태에만 · 차트는 선 하나)은 그대로 두고**,
랜딩 C안의 브랜드 요소만 다시 가져온다. 글자 크기·밀도·표는 v2 그대로.

## 대표 버튼(brand)을 쓰는 곳 — 이 목록 밖에는 쓰지 않는다

- 로그인 `로그인`
- 가입 마지막 `가입하고 시작하기`
- 직원 출퇴근 `출근하기` (퇴근은 실수 방지로 흰 버튼 그대로)
- 온보딩 마지막 단계 (웹)

나머지 주 동작(저장 · 게시 · 승인 · 객실 상태 바꾸기)은 남색 알약. 같은 카드 안에 대표 버튼과 남색 주 버튼을 같이 두지 않는다.

## 2026-11-22 홀마크 점검 · 아스트릭스

### 홀마크 (AI 티 점검, 메인 랜딩 제외)

`Nutlope/hallmark` 의 `sloplint --scope app --render` 로 앱 화면 19개(사장님 15 · 직원 1 · 운영자 2 · 로그인 1)를 점검하고
"polish"(배치·체계는 그대로, 지적된 것만)로 고쳤다. 바닥 규칙 위반 **444 → 148건**, 링크·제목은 하나도 안 빠짐.

고친 것: 입력칸 테두리 대비 3:1 이상(`--pm-field-line`), 대표 버튼 주황 한 단계 진하게(흰 글자 3:1 이상), 비활성 글자 대비,
흐리게만 하던 비활성 버튼 → 면·글자·커서, 진행 막대 width 애니메이션 → transform, 자간 넣은 라벨 제거, 10.5px 글자 → 11px,
아이콘 동그라미 바탕 제거, 숫자 tabular-nums, 제목 `text-wrap: balance`, 제목 단계(h1 → h3) 바로잡기, 옆 막대(side stripe) 제거,
떠 있는 창은 선 없이 그림자 하나, `html, body { overflow-x: clip }`, 100vw 계산 제거, 좁은 화면 운영자 검색 줄 넘침.

남긴 것(이유):

- 랜딩 공용 `global.css` 의 일·중 글꼴 지정 — 랜딩 파일이라 손대지 않음
- 사이드바 + 위쪽 바 sticky 두 개 — 서로 옆에 있어 겹치지 않음 (린터 오탐)
- 휴대폰 메뉴가 스크립트로 열림 — 앱은 스크립트 없이 동작하지 않음
- 영문 대문자 — RAINBOW HOTEL 같은 업장 이름, WOOJOO ORBIT 상품명 (고유명사)
- 표 빈칸 "–", 현장 메모 안의 "—" — 사용자 데이터 · 표 관례
- 요금표 칸 입력칸 — 표 격자가 칸 경계라 진한 테두리를 두지 않음
- 4px 간격 단위 밖 값 · 같은 상자 모양 반복 — polish 범위 밖 (배치 재설계 때)

### 아스트릭스 (Meta 디자인 시스템, 0.7.17 베타)

- 범위: **로그인 · 가입 · 비밀번호 재설정 · 온보딩 · 초대 · 근로계약 서명 · 운영자(/admin)** 의 버튼과 글자 입력창. 사장님 업무 화면(/app)은 기존 부품 그대로
- 화면은 아스트릭스를 직접 쓰지 않고 `src/ui/pms/components/Astryx` 의 `AxButton`(PmButton 과 같은 props) · `AxTextField` 를 쓴다
- 색 · 글꼴 · 둥글기는 `astryx-theme.css` 에서 우리 토큰으로 덮음 (알약 버튼, 대표 버튼 주황, 반투명 입력 테두리, 한국어 문구 `ko-KR`)
- 랜딩 공용 `global.css` 는 앱·운영자 화면에서만 `pms-global.css` 로 `@layer reset` 안에 불러온다 — 아스트릭스 버튼 모양이 초기화에 지워지지 않게. 랜딩은 그대로
- 아직 그대로: 선택 상자(select) · 체크박스 · 날짜 · 여러 줄 입력(textarea)
